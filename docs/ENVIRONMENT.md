# Переменные окружения

Локально значения читаются из `.env.local` (создаётся копированием `.env.example`). В продакшене их задают в настройках хостинга. Файлы `.env*`, кроме `.env.example`, исключены в `.gitignore`.

| Переменная | Где используется | Локально | Продакшен | Секрет |
|---|---|---|---|---|
| `DATABASE_URL` | `src/lib/db.ts` | можно оставить пустым — будет SQLite в `data/` | обязательно, pooled Postgres URL | да |
| `SESSION_SECRET` | `src/lib/db.ts`, `src/lib/server.ts` — HMAC-подпись приватных ссылок на заявки | желательно; иначе генерируется в `data/local-access.json` | обязательно, ≥ 32 байт случайных данных | да |
| `OWNER_PASSWORD` | `src/lib/server.ts` — первичный пароль кабинета `/admin` | желательно; иначе генерируется в `data/local-access.json` | обязательно, длинный уникальный пароль | да |
| `NEXT_PUBLIC_SITE_URL` | `src/app/robots.ts`, `src/app/sitemap.ts` | `http://127.0.0.1:3000` | публичный HTTPS-адрес | нет (попадает в браузер) |

Служебные переменные, которые задаёт среда, а не вы: `VERCEL` (включает строгий режим: без трёх серверных переменных приложение откажется работать), `NODE_ENV`, `TEST_URL` (адрес для `tests/integration.mjs`, по умолчанию `http://127.0.0.1:3000`).

## Генерация значений

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

Запустите дважды: одно значение для `SESSION_SECRET`, второе — для `OWNER_PASSWORD`.

## Важно

- Смена `SESSION_SECRET` делает недействительными все ранее выданные клиентам ссылки на заявки.
- `OWNER_PASSWORD` — только начальный пароль. После смены пароля в кабинете («Доступ») хеш нового пароля хранится в базе, и переменная больше не используется для входа.
- Если `DATABASE_URL` задан, а `SESSION_SECRET`/`OWNER_PASSWORD` нет, production-сборка не пустит в кабинет («Не настроен доступ владельца»).
- Кнопка «Войти в локальное демо» доступна только без `DATABASE_URL`, вне Vercel и на `127.0.0.1`/`localhost`.
- Префикс `NEXT_PUBLIC_` встраивает значение в клиентский JavaScript. Не давайте этот префикс секретам.
